UnrEal 初始号（网页版）
====================================

一、怎么打开
  双击「打开网站.bat」，或直接双击 index.html（用 Chrome / Edge 打开）
  部署上线后直接用网址打开
  ★ 打开先登录：
     老板密码 060213 → 看完整数据（邮箱/密码），复制 = 账号---密码---邮箱---邮箱密码
     员工密码 自定义 → 只看到 编号/皮肤/图片，复制只能复制编号，看不到也拿不到密码
     密码不对进不去；关浏览器后需重新登录

二、安全设计（员工扒不到密码）
  · 老板数据整个文件用老板密码 AES-256 加密（PBKDF2 十五万次迭代），不输对密码
    连源码里都只有密文，抓包/翻缓存/看源码都拿不到明文
  · 员工包里根本没有密码字段，员工端是「不存在」而不是「看不见」
  · 网页里只存密码的 SHA-256 哈希，明文密码不落盘
  · 换密码：改 app.js 里 ROLE_HASH 两个哈希值 + 生成网站数据.py 里 BOSS_PASS，
    重新生成数据包并发布即可

三、老板怎么同步数据（每日更新）
  方式 A（推荐）：查询完商店后运行
     python 生成网站数据.py        （自动找最新的 账密.xlsx / 查询结果）
     生成两个文件后重新发布网站即可，老板员工打开自动拿到新数据
  方式 B（网站内）：
     老板登录 → 导入数据 → 顶栏「导出加密包 / 导出员工包」下载两个 json
     把文件替换到网站目录重新发布；加密包也可以在本地网站直接导入

四、本地导入数据
  1. 老板登录后点「导入数据」，选 Excel / CSV / JSON
  2. 也可以直接把文件拖进页面
  3. 支持：账密表、查询结果表、加密数据包(data-enc.json)、员工包
  4. 第一行有表头会自动认列；没有表头按「账号 / 密码 / 邮箱 / 邮箱密码 / 皮肤」顺序读
  5. 重复导入同一个账号 = 更新（不会出现两条），编号不区分大小写

五、卡片怎么看
  编号：账号名（例 yesx0008）
  邮箱：该账号邮箱（员工身份不显示）
  每日商店：今天刷的皮肤，用顿号隔开
  地区：暂时没有数据，等有地区数据后自动显示

六、复制按钮
  老板点「复制」→ 账号---密码---邮箱---邮箱密码
  例：yesx0008---xey2wdxm---zhuo7003303@163.com---weix33063
  员工的复制按钮 = 只复制编号
  点完右下角会弹「已复制」，直接去记事本 Ctrl+V

七、查看图片
  点「查看图片」，弹出商店长图版：
    · 顶部：商店信息 编号 / 送初邮
    · 中间：每日商店 4 格，带皮肤图、价格 VP、皮肤名
    · 下面：夜市（没有就显示「夜市未开放」）
  图按皮肤名实时从 Riot 官方图片库取，点开才加载，列表页不加载图片

八、搜索 / 筛选
  顶部搜索框：编号、皮肤名都能搜
  右上角「筛选」：范围（全部/有商店/有夜市/无数据）＋ 排序

九、皮肤库
  图片来自 valorant-api 官方 CDN，需要联网；断网显示「暂无图片」
  内置离线对照表 3857 条，断网也能认出大部分皮肤名；联网打开自动更新（7 天缓存）

十、文件说明
  index.html            页面
  style.css             样式
  app.js                逻辑（含登录/加密）
  data-enc.json         老板加密数据包（发布到网上）
  data-staff.json       员工数据包（发布到网上）
  生成网站数据.py        每日同步脚本（python 生成网站数据.py）
  assets/               Excel 解析库 + 皮肤离线表
  打开网站.bat          本地双击启动

【员工密码管理（多员工密码）】
1. 老板登录后，顶栏点「员工密码」打开管理面板。
2. 可以添加 / 删除多个员工密码，每个员工可以用不同的密码登录，登录后功能完全一样（无邮箱、无复制）。
3. 新密码在你自己电脑上立即生效；要让员工那边也生效，点「导出员工包」下载新的 data-staff.json，发回来重新发布覆盖线上文件即可。
4. 「恢复默认」会把员工密码重置为 123456。
5. 员工密码只存哈希值（SHA-256），导出的员工包里看不到明文，扒文件也扒不出密码。

【2026-11-14 重大更新：网页直传 + 全自动同步上线】
网站已配好云端仓库（Cloudflare Pages Function + KV），日常操作彻底简化：

一、老板上传数据（新方式，推荐）
1. 老板登录 → 点「导入数据」选文件（xlsx/csv/json/txt 都行）
2. 导入完成会自动同步到云端，员工下次登录立即看到最新数据
   —— 不需要再跑 生成网站数据.py，也不需要双击 更新网站.bat

二、员工密码（全自动同步）
1. 老板登录 → 「员工密码」面板 → 添加/修改/删除，改动自动同步云端，员工立即生效
2. 换浏览器/换电脑也不用重新设置——密码清单存在云端，打开面板就能看到
3. 本机没存过明文的云端密码会显示为「云端密码（本机无明文）」，可删除

三、生成网站数据.py 和 更新网站.bat 还能用吗？
能，当备用：bat 只负责更新「网页代码」（改界面/功能时用），日常数据同步用网页上传即可。
注意：如果用 bat 上传了旧的 data-staff.json（内含旧员工密码哈希字段），云端密码以网页面板为准，员工密码不会被 bat 覆盖（data-staff.json 里的 staffHashes 字段已不再被读取）。

四、安全说明
- 老板密码从不离开你的浏览器：云端只存一个由密码派生的校验令牌（PBKDF2），上传接口没有令牌无法调用
- 员工密码只存哈希；老板加密包 AES-256 加密存储
- 云端数据持久保存，你的电脑关机不影响员工访问

【每日数据过凌晨 0 点自动清空（2026-11-15 更新规则）】
1. 每天过凌晨 0 点，网页上的账号列表整体清空：账号、密码、邮箱、每日商店全部不显示，总数变 0，顶部出现黄色提示条「数据已过期」。
2. 清空只针对数据：老板密码、员工密码、员工备注完全不受影响，照旧可以登录。
3. 老板号导入当天的新表后，提示条消失、当天数据立刻恢复，并自动同步云端，员工刷新即可看到。
4. 跨天导入是「整表替换」：昨天有、今天新表里没有的账号会被清掉，不留旧数据。
5. 判断依据是数据日期（云端记录的上传日期 / 云端员工包里的 date），不依赖电脑开机，也不依赖定时任务；手机清过缓存也能正确判断。
6. 如果某天不导入新数据，网页就一直保持空列表状态，不会显示昨天或更早的旧数据。
